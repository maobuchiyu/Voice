# AcousticLab 网页原型

根据工作区中的 `PROJECT_PLAN.md` 制作的独立静态网页预览。

## 打开

可直接用浏览器打开 `index.html`，无需安装依赖。

需要在开发浏览器中检查画面时，双击 `start-preview.cmd`，保持命令窗口打开，然后访问 <http://127.0.0.1:8000/>。脚本使用 Windows 的 Python 3 启动静态文件服务器，仅监听本机地址。按 `Ctrl+C` 可停止服务器；若 8000 端口被占用，窗口会显示错误。

## 说明

- 当前是界面原型，所有设备状态、图表和测量读数均为模拟数据。
- 可切换测量模式和 FFT 长度，暂停/恢复绘图，模拟测试音，并导出 CSV 或 JSON 示例数据。
- 横轴刻度标签和图内竖直网格使用相同的对数频率坐标；衰减模式切换为时间轴。
- 实时频谱、电气回环、逐点扫频和衰减模式会分别更新曲线、坐标标签、说明和读数。
- 默认显示示波器视图，提供 CH1 波形、时基、垂直档位、触发电平/边沿、AC/DC 耦合、RUN/STOP、AUTOSET 和 SINGLE；频谱分析仍可从顶部标签切换。
- “测试信号发生器”和状态面板只演示界面交互，不连接开发板，也不产生声音输出。
- 电平单位为相对 dBFS；没有声学校准时不表示 dB SPL。
- 在“频谱分析 → 电气回环”查看谐波分析面板，展示 H1～H5 的频率、dBFS、dBc、幅度比及总 THD；频谱同步标注各阶谐波。
- 谐波和频谱共用模拟分量数据。默认基波为 1 kHz，开启测试音后随频率、电平调整；暂停时保持当前帧。相对谐波比例为预设演示值，不模拟真实硬件的失真变化。
- THD 支持基波 100 Hz～4 kHz，按 H2～H5 幅度平方和开方除以 H1 计算，不含噪声；其他模式不输出 THD。支持单独导出谐波 CSV，频谱 JSON 也包含谐波数据。
