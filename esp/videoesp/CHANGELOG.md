# ESP 版本记录

## v0.3.0 — 2026-10-05

包含 v0.2 的 ESP/网页前置功能，并与 C5 v0.3.0 当前协议对接：

- 新增 THD/H1–H5、121 点扫频幅相、校准有效性及结果导出；测试音确认后才启动 THD。
- 新增 4096 FFT 控制、C5 相对 A/C/Z 与频带结果、30 秒浏览器瀑布图、DC/Nyquist 完整谱分块拼装。
- 新增 loop/mic 校准 JSON 导入、显式 NVS 保存、IDLE 分块加载/最终ID确认、清除与中断恢复入口。
- 无效、部分、暂停、离线快照分别显示；增益/路径变化不继续沿用旧校准，未完成完整谱不导出。
- 保留 Arduino、115200 8N1、无查表 CRC16、非阻塞 HTTP、刷新交接和运行诊断。

Release 构建、39 项 JS 协议检查、基础15类/连续刷新6次与新增14类浏览器场景通过，浏览器错误0。C5同源6项数值/主循环测试及真实帧双解析通过。未检测到COM8，本版未烧录；高级测量精度、真机刷新/校准断电保存和长期运行仍待验收。

## v0.1.1 — 2026-10-01

针对用户反馈刷新后卡住、随后断线，以及诊断没有 ESP 周期数据的问题：

- HTTP 网页传输改为每轮至多 1024 字节的非阻塞 socket 写入，读取请求也有界；慢客户端 5 秒无进展即关闭，UART 每轮继续轮询。
- WebSocket 留两个连接槽用于刷新交接，建立新连接时关闭旧测量连接，仍只保留一个活动客户端。
- hello 和首批诊断移到 WebSocket 回调返回后发送，较大的 JSON 请求/输出缓冲移出回调栈。
- 页面退出主动关闭 WebSocket；首次连接立即发送诊断，不必等下一秒。
- 补充接收字节、ESP 复位原因、主循环最高耗时、循环栈最低余量；`/api/info` 提供同样关键计数，可独立于 WebSocket 检查。
- 修复命令失败 result=−1 未被序列化的问题。
- 每轮让出 1 ms 供系统任务运行，避免持续轮询占满主循环所在核心。

Release 编译和 COM8 上传成功，所有写入段哈希校验通过。串口确认 v0.1.1、16 MB Flash、8,385,943 B PSRAM；启动后循环栈余量 5,328 B。协议 14 项检查通过；原 15 类浏览器场景及额外 6 次连续刷新通过。浏览器测试使用本地夹具，不替代真实热点刷新验收。

截图中的 C5 采样块数和 uptime 表明至少收到过 STATUS；ESP 诊断显示“—”不能解释为接收计数为 0。已修复发现的刷新交接与阻塞路径；尚无用户卡死时的异常串口日志，不能断言已证明唯一根因。手机连续刷新、真实 UART 计数、NVS 和长期稳定性仍待确认。

## v0.1.0 — 2026-10-01

完整 v0.1 网页、UART/CRC 桥接、模式确认、显示暂停/单次、配置保存、导出及诊断。频谱和测试音按 C5 能力启用，C5 FFT/DDS 当时仍待实现。Release 构建、14 项协议及 15 类浏览器检查通过；后续用户确认已自行烧录该版。
