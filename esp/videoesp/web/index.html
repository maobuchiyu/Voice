使用工作台

  1. 连接 AcousticLab 热点，打开 192.168.4.1。两板分别用 USB 供电，只接 UART 与共地，3V3 不互连。
  2. 选择当前物理输入接法，再点“开始分析”。模式显示 RTA 后，设备开始上传电平与波形。
  3. 暂停显示会保持当前图表和读数；“单次预览”捕获下一份图表数据。C5 继续采样。
  4. 调整显示设置或输入记录后，点击“保存到设备”保留设置。测试音不会在开机或重连后自动开启。
  5. CSV / JSON 导出当前显示快照。波形是 512 样本的 64 组包络，频谱是 256 点预览；两者均不等同于原始音频或完整频谱。

当前 C5 未实现 FFT 或测试音时，相应图表和输出控制会显示支持状态。THD、扫频、衰减、瀑布图与完整频谱导出属于后续版本。
